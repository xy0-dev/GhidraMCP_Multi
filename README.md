# GhidraMCP_Multi

Fork of [LaurieWired/GhidraMCP](https://github.com/LaurieWired/GhidraMCP) with multi-program support: work with several programs open in one CodeBrowser (`list_programs`, `switch_program`, and an optional `program` argument on every tool). For installation and general usage, see the upstream README. Build: `gradle` in `extension/` with `GHIDRA_INSTALL_DIR` set.
